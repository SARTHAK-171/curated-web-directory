A clearer way to explore

The useful internet. Without the noise.

ORBIT is a personal, curated directory of websites, tools and digital resources. It gives useful discoveries a clear home, so you can spend less time hunting for links and more time learning, building and exploring.

01 / What it is

A starting point, not another platform.

ORBIT brings useful corners of the web together in one organised place. Each resource has a clear description and a direct path to its own website, with extra details available when they help you decide whether it is worth opening.

02 / Why it exists

Finding the good stuff takes time.

The internet has more tools, tutorials and experiments than anyone can keep track of. Search results and random bookmarks can make it harder to find a useful starting point. ORBIT keeps a smaller, organised collection that is easier to browse and return to.

03 / How it is organised

A few simple rules.

Every entry should earn its place by being useful, understandable and easy to revisit.

  • 01

    Quality over quantity

    A short, useful collection is better than a huge pile of random links.

  • 02

    Clear descriptions

    Each listing should explain what a resource does before you open it.

  • 03

    Sensible organisation

    Categories and useful details make the collection easier to navigate.

  • 04

    Useful links

    Entries point to the resource itself, with information reviewed rather than guessed.
