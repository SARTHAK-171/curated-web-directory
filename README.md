# ORBIT

**A curated corner of the internet.**

ORBIT brings useful websites, AI tools, developer resources, learning platforms, and places worth exploring into one thoughtfully organised directory.

Discover less. Find better.

## ✦ Features

- Curated resources organised by category
- Search, filter, and sort to find the right tool
- Resource pages with details and related discoveries
- Save favourites locally in your browser
- Responsive interface for desktop and mobile

## ⚙️ Built with

**HTML · CSS · JavaScript · JSON**

No frameworks. No backend. Just a lightweight static website.

## 🚀 Run locally

Clone the repository, open the folder in VS Code, and launch the project using a local server such as **Live Server**.

> Saved resources are stored in your browser and do not sync across devices.
